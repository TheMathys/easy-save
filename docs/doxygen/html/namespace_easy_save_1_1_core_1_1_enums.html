enum EasySave.Core.Enums.BackupState

Represents the current state of a backup job.

Enumerator
Inactive 

The job is pending or is not currently running.

Active 

The backup is currently running (copying files, calculations, etc.).

Paused 

The backup is temporarily paused by the user. Progress values remain frozen.

Completed 

The backup completed successfully (100%).

Error 

A critical error occurred and the backup was interrupted.

enum EasySave.Core.Enums.LogDestination

Where backup log entries are written: local files only, centralized server only, or both.

Enumerator
Local 

Logs are written only to local daily files (current behavior).

Centralized 

Logs are sent only to the centralized log server (no local files).

LocalAndCentralized 

Logs are written both locally and sent to the centralized server.
