IReadOnlyList< string > PriorityExtensions = Array.Empty<string>() [get]
 Priority file extensions (e.g. ".doc", ".pdf"). Used to enforce the global priority rule: as long as at least one priority file (extension in this list) is still pending on at least one running backup job, no non-priority file may be transferred on any job. This applies across all jobs when several run in parallel. Empty or null = no priority rule (all files are treated equally). Comparison is case-insensitive.
