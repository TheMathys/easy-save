Detailed Description

Executes backup jobs in parallel when multiple are selected, otherwise runs a single job. Logging, real-time state, full/differential strategy. Progress by size (bytes) with ETA and report during file copy. Blocks start and stops during backup when business software is detected. State and log writes are coordinated so that the state file and logs remain consistent when several jobs run concurrently.
